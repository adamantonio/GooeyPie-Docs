# GooeyPie Documentation

**Live Documentation:** [https://gooeypie.dev](https://gooeypie.dev)

This repository contains the source code for the official documentation of **GooeyPie** — an easy-to-use Python GUI library for Windows, Mac, and Linux, designed especially for beginners. 

The site is built using [Starlight](https://starlight.astro.build) by Astro.

## 🥧 About GooeyPie

GooeyPie makes building modern, beautiful desktop applications simple. Built on top of `customtkinter`, it offers:
- **Beginner Friendly:** Start building instantly with basic Python knowledge.
- **Crystal Clear Docs:** Plain English guides, code snippets, and video demos.
- **Consistency is Key:** Identical logic for handling events, styling, and options across the library.
- **Modern & Beautiful:** Sleek, modern, and professional interfaces right out of the box.
