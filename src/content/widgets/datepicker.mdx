    description: Gets or sets the maximum date that can be selected in the Date widget.
  - name: date_str
    type: string
    description: Gets or sets the date of the Date widget as a string in the format specified by the `format` property. Setting this property will update the `date` property to match the new date.
  - name: width
    type: integer
    description: Gets or sets the width of the widget in pixels.
  - name: disabled
    type: boolean
    description: Gets or sets whether the date widget is disabled. When disabled is set to True, the date widget does not respond to user interactions.
  - name: allow_manual_input
    type: boolean
    description: Gets or sets whether the user is allowed to manually input a date into the date widget. When allow_manual_input is set to True, the user can type a date into the date widget in addition to selecting a date from the calendar. The default value is True.
  - name: format
    type: string
    description: Gets or sets the format of the date displayed in the date widget. The format should be a string that follows the [strftime format codes](https://docs.python.org/3/library/datetime.html#strftime-and-strptime-format-codes). The default format is "%Y-%m-%d", which displays the date as "2024-06-01".
  - name: localization
    type: string
    description: Gets or sets the localization of the date widget. The localization should be a [locale string](https://simplelocalize.io/data/locales/) such as `"fr_FR"` or `"en_US"`. The default localization is the empty string `""`, which uses the system default locale.

The Date widget allows the user to select a date from a calendar dropdown or manually input a date. The selected date can be accessed and modified through the `date` property, which is a `datetime.date` object, or through the `date_str` property, which is a string representation of the date in the format specified by the `format` property. The Date widget also provides methods for manipulating the date, such as adding or subtracting days, months, or years.
