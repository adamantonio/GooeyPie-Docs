---
title: Switch

syntax: my_switch = gp.Switch(label_text)

parameters:
  - name: label_text
    type: string
    description: The text of the switch.

properties:
  - name: text
    type: string
    description: Gets or sets the text of the switch.
  - name: value
    type: boolean
    description: Gets or sets the value of the switch. Setting this property to `True` will turn the switch on, while setting it to `False` will turn it off.
  - name: width
    type: integer
    description: Gets or sets the width of the switch, including the label.
  - name: height
    type: integer
    description: Gets or sets the height of the switch, including the label.
  - name: switch_width
    type: integer
    description: Gets or sets the width of the switch itself, excluding the label.
  - name: switch_height
    type: integer
    description: Gets or sets the height of the switch itself, excluding the label.
  - name: disabled
    type: boolean
    description: Gets or sets whether the switch is disabled. When disabled is set to `True`, the switch does not respond to click events.

methods:
  - name: toggle()
    parameters: none
    returns: '`None`'
    description: Toggles the value of the switch. If the switch is currently on, it will be turned off, and if it is currently off, it will be turned on.

exclude_events:
  - on_key_press
  - on_focus_gained
  - on_focus_lost

events:
  - name: on_change(event_function)
    description: The function to call when the switch value changes. This event is triggered whenever the user clicks on the switch to change its value, or when the value is changed programmatically.

styles:
  - name: border_color
    description: The color of the border of the switch.
    default: '"transparent"'
  - name: border_width
    description: The width of the border of the switch.
    default: "0"
  - name: button_color
    description: The color of the switch button.
  - name: button_disabled_color
    description: The color of the switch button when it is disabled.
  - name: button_hover_color
    description: The color of the switch button when it is hovered over.
  - name: on_bg_color
    description: The background color of the switch when it is on.
  - name: off_bg_color
    description: The background color of the switch when it is off.
  - name: text_color
    description: The color of the text of the switch.
  - name: text_disabled_color
    description: The color of the text of the switch when it is disabled.
  - name: font_name
    description: 'The font of the text of the button. Either an installed font or a generic font name: `"serif"`, `"sans-serif"`, `"monospace"` or `"system"`'
    default: '"system"'
  - name: font_size
    description: The size of the text of the button.
    default: "12"
  - name: font_weight
    description: 'The weight of the text of the button. Either `"normal"` or `"bold"`.'
    default: '"normal"'
  - name: font_style
    description: 'The style of the text of the button. Either `"normal"` or `"italic"`.'
    default: '"normal"'
  
---

A Switch is a widget that can be toggled on or off by the user. It consists of a switch button and an optional label.
