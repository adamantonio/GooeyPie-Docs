---
title: RadioGroup

syntax: my_radio_group = gp.RadioGroup(options, orientation)

parameters:
  - name: options
    type: list of strings
    description: The labels for the radio buttons in the group. The number of items in the list determines how many radio buttons are in the group.
  - name: orientation
    type: string
    description: '<strong>Optional</strong>. The orientation of the radio buttons in the group. Either <code>"horizontal"</code> or <code>"vertical"</code>. Default is <code>"vertical"</code>.'

properties:
  - name: selected
    type: string
    description: Gets or sets the label of the currently selected radio button in the group. Setting this property will change the selected radio button to the one with the specified label. Setting `.selected` to `None` will deselect all radio buttons in the group.
  - name: selected_index
    type: integer
    description: Gets or sets the index (starting from 0) of the currently selected radio button in the group. Setting this property will change the selected radio button to the one at the specified index.
  - name: orientation
    type: string
    description: Gets or sets the orientation of the radio buttons in the group. Either `"horizontal"` or `"vertical"`. Default is `"vertical"`. This property cannot be changed after the radio group is added to a layout.
  - name: options
    type: list of strings
    description: Gets the labels for the radio buttons in the group. The options cannot be changed after the radio group is created.
  - name: width
    type: integer
    description: Gets or sets the width of the radio group in pixels.
  - name: height
    type: integer
    description: Gets or sets the height of the radio group in pixels.
  - name: disabled
    type: boolean
    description: Gets or sets whether the radio group is disabled. When disabled is set to `True`, the radio buttons in the group do not respond to click events.

methods:
  - name: disable_item(item_label)
    parameters: item_label
    returns: '`None`'
    description: Disables the radio button with the specified label. A disabled radio button does not respond to click events and is visually indicated as disabled.
  - name: enable_item(item_label)
    parameters: item_label
    returns: '`None`'
    description: Enables the radio button with the specified label.
  - name: disable_index(index)
    parameters: index
    returns: '`None`'
    description: Disables the radio button at the specified index. A disabled radio button does not respond to click events and is visually indicated as disabled.
  - name: enable_index(index)
    parameters: index
    returns: '`None`'
    description: Enables the radio button at the specified index.


exclude_events:
  - on_key_press
  - on_focus_gained
  - on_focus_lost

events:
  - name: on_change(event_function)
    description: The function to call when the selected radio button in the group changes. This event is triggered whenever the user clicks on a radio button in the group or when the selected radio button is changed programmatically.

styles:
  - name: checked_border_color
    description: The color of the border of the selected radio button in the group.
  - name: checked_border_width
    description: The width of the border of the selected radio button in the group.
    default: "5"
  - name: hover_color
    description: The color of the radio buttons in the group when hovered over.
  - name: size
    description: The size of the radio buttons in the group.
  - name: text_color
    description: The color of the text of the radio buttons in the group.
  - name: text_disabled_color
    description: The color of the text of the radio buttons in the group when they are disabled.
  - name: unchecked_border_color
    description: The color of the border of the unselected radio buttons in the group.
  - name: unchecked_border_width
    description: The width of the border of the unselected radio buttons in the group.
    default: "3"
  - name: font_name
    description: 'The font of the text of the button. Either an installed font or a generic font name: `"serif"`, `"sans-serif"`, `"monospace"` or `"system"`'
    default: '"system"'
  - name: font_size
    description: The size of the text of the button.
    default: "12"
  - name: font_weight
    description: 'The weight of the text of the button. Either `"normal"` or `"bold"`.'
    default: '"normal"'
  - name: font_style
    description: 'The style of the text of the button. Either `"normal"` or `"italic"`.'
    default: '"normal"'

A RadioGroup is a group of radio buttons, of which only one can be selected at a time. Use Radio Buttons when the user must select exactly one option from a small set of mutually exclusive choices that should all be visible at once.
