An ImageButton is a button that displays an image. It can also optionally display text in addition to the image. The image can be positioned to the left, right, top or bottom of the text.


## Examples
### Media Player
In this (totally fake) media player, three image buttons are used for play, pause and shuffle controls. This shows how an ImageButton can have optional text in addition to the image. The images are from [IconsDB](https://www.iconsdb.com/).
